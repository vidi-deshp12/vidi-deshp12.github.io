Featured Projects

🧠

FactGraph

LLMs annotating factual claims have no evidence trail; when they're wrong, nothing flags it. Built a knowledge-graph-grounded verification pipeline to catch these errors at scale on the FEVER benchmark.

  • Rescued 62% of LLM annotation errors (133 of 213) by cross-checking claims against Wikidata graph evidence; no retraining, only evidence routing
  • Boosted NEI recall 4.9× (0.17 → 0.83) by grounding ambiguous claims in structured evidence instead of LLM parametric knowledge
  • Three-route retrieval system: exact match → property lookup → MiniLM semantic fallback over a 3,990-triple knowledge graph
LLaMA 3.1 spaCy Neo4j DeBERTa Wikidata Python

Image Captioning with CNN–RNN

Built a CNN–RNN image captioning system using VGG16 for visual feature extraction and an LSTM decoder for sequence generation, trained on 8K Flickr images with 40K+ captions.

  • Implemented a custom image-caption preprocessing and tokenization pipeline to standardize the Flickr8k corpus for sequence-to-sequence training
  • Improved caption quality by 12% BLEU using beam search decoding over greedy decoding; same model, better inference
  • Established an architecture baseline that directly informed the later move to CLIP–GPT-2 for the accessibility domain
VGG16 LSTM TensorFlow Keras Beam Search Flickr8k
